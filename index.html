Zero-Cloud Privacy & Cryptographic Verification

Smart WebRTC Classroom stores zero audio, video, or private student logs on external servers.

WebRTC DTLS-SRTP Encryption

All media tracks and DataChannels are end-to-end encrypted across browser peers using DTLS 1.2/1.3 and SRTP AES-128-GCM cipher suites.

SHA-256 File Integrity

Every binary file transferred is hashed at origin using the browser's native Web Crypto API and re-verified at destination.

Zero Telemetry / Cloud Logs

No trackers, analytics, or third-party cookies exist in this codebase. Signaling traffic is ephemeral and never persisted.

Operating Guide & Network Setup

1. Stage 1 — Zero-Server Standalone Mode (GitHub Pages)

In Zero-Server mode, no backend is needed. Click Generate Student Join Token in the dashboard. Copy the token or show the QR code to the student. The student inputs the offer token, generates an answer, and returns it to complete the connection!

2. Stage 2 — Reliable Classroom Server Mode (WebSocket + SFU)

When the companion Node.js server is running (npm start), connections establish automatically! Students type the 6-digit room code, you click Approve in the Participants tab, and WebRTC connects immediately over LAN.

3. Dedicated Local LAN Operation

Operating exclusively over local Wi-Fi or Ethernet switch. WebRTC establishes a direct host LAN path (<5ms latency) without sending any traffic or ICE queries to external internet STUN/TURN servers.
